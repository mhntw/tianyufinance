# 添钰财务管理系统

本地单机桌面财务软件（Tauri 2 + 原生系统 WebView），**无需联网、无需登录、无云端依赖**。
专为小微企业与个体经营设计，采用标准**复式借贷记账**，账套保存在本机文件。

> 交互与科目体系参照金蝶精斗云·云会计，数据层面与其对齐，习惯金蝶的用户可零成本上手。

---

## 功能

- **记账凭证** — 复式借贷，逐行选科目 + 借/贷 + 金额，实时校验借贷必相等，不平不能保存
- **会计科目** — 预置标准科目，可自由增删改；已被使用的科目禁止改类别（防历史数据错乱）
- **账务账簿** — 科目余额、明细账、多栏账、试算平衡，全部从凭证逐笔派生
- **财务报表** — 资产负债表、利润表、现金流量表、费用明细、项目利润
- **期末处理** — 折旧/工资/增值税/附加税自动计提、结转损益、结账/反结账、年结
- **固定资产 & 工资** — 资产卡片 + 按月计提折旧自动生成凭证；工资计提/发放自动入账
- **数据互通** — 导入金蝶 KIS 账套（`.ais`）、与精斗云云会计互导凭证/科目余额 Excel
- **多账套 & 安全** — 一机多账套隔离；自动备份 + 高风险操作即时备份 + 手动导出 JSON

## 下载安装包

Windows / macOS 安装包由 GitHub Actions 自动构建，发布到 **[Releases](https://github.com/mhntw/tianyufinance/releases)**。

| 平台 | 产物 |
|---|---|
| Windows | `*-setup.exe`（NSIS） |
| macOS | `*.dmg`（Apple Silicon） |

> macOS 包未签名，首次打开请右键 →「打开」。

## 数据存储位置

账套与备份保存在操作系统的应用数据目录：

| 平台 | 路径 |
|---|---|
| macOS | `~/Library/Application Support/添钰财务/` |
| Windows | `%APPDATA%\添钰财务\` |

目录内：`books/`（账套）、`backups/`（备份）、`trash/`（回收站）、`exports/`（手动导出）。
软件内「设置 → 打开数据目录」可直接打开该位置。

**迁移**：把整个目录拷走即完成数据迁移。

## 开发

```bash
cd tauri
npm install
npm run tauri dev       # 桌面调试窗口，前端热改即时生效
```

前端源码：根目录 `index.html` / `css/` / `js/`；桌面壳：`tauri/`。

## 发布

推 `v` 开头的 tag 触发自动构建：

```bash
git tag v0.7.0 && git push origin v0.7.0
```

版本号自动从 tag 同步到 `tauri.conf.json`，无需手动改。
Windows 先构建创建 Release，macOS 后附加产物到同一 Release，约 10-20 分钟完成。
