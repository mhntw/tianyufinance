          如何设置金额取数规则？

          生成凭证时，金额取数规则：

          1. 余额取数：取科目当前期间期末余额，按方向自动借贷。

            云同步

            用 WebDAV（坚果云等）在两台电脑间手动同步账套：一台点「云备份」，另一台点「云同步」。软件不在后台联网，也不会自动同步。

            云备份：本机 → 云端；云同步：云端 → 本机（覆盖前自动留本机备份，可在「查看备份」中回滚）。换机前请先在旧电脑点「云备份」。

            记录全部账套的操作日志与生命周期事件（新建/删除/导入/还原账套等），读取全局 changelog.json、保留最近 1000 条。即使某账套被覆盖恢复或删除，本卡记录也不受影响，可作历史对账；审计明细（改前/改后、反结账原因）请在左侧「操作日志（当前账套）」查看。

            新建账套

            启用期间 = 账套第一笔账所在月份，默认为本月；如账务从更早月份开始，请先在此选好起始月（建账后仍可在「系统设置 → 基本信息」调整）。创建后将自动带入对应准则的常用科目表；建议接着到「期初余额」录入期初数据。

            重命名账套

            仅更改账套的显示名称（顶部栏与报表表头），不影响「启用期间」与任何账务数据。

            修改启用期间

            启用期间 = 账套记账起点。账套已有凭证/期初/结账数据时修改，仅影响期间下拉的起点与「启用期间」显示，不影响任何凭证与报表数据。

            云同步设置

            应用密码已保存在本机（上面显示为星号），升级软件不会丢失；要更换请清空后输入新密码。

            在坚果云网页端：账户信息 → 安全选项 → 第三方应用管理 → 添加应用密码。

            变更会计准则

            切换将迁移损益类科目编码（5xxx↔6xxx）于科目表 / 期初余额 / 凭证分录 / 现金流映射，并重灌报表取数规则。不可逆，强烈建议先做备份。此操作需验证操作密码。

            新增科目
            注意：科目名称修改后，以前期间凭证、报表上的科目名称都会变成新的科目名称。
